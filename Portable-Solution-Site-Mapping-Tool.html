How to use this tool

  1. Pick a structure — Choose a shelter from the sidebar, then click the map to place it.
  2. Arrange it — Drag to move, use the handle to rotate. Turn on Snap to line it up flush with a neighbor.
  3. Check for overlap — Red means footprints collide. Amber means clearance buffers touch. Fix before finalizing.
