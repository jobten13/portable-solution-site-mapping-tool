VPC Mapping Tool — Quickstart

Open the app, place structures, save — one sheet for field use.

1. Open

Open VPC Mapping Tool.html in Chrome, Edge, or Firefox (no install). Network needed first for imagery, search, and PDF libraries; then many features work offline.

Offline: No tiles? Enter lat, lng in search (e.g. 34.05, -118.25) and Search.

2. First layout

  1. Site: Header search (address or coords). Setup ▾ — operation name for print/PDF.
  2. Pick: Sidebar Vendor tab → model. Status line shows placement mode.
  3. Place: Click map. Repeat.
  4. Edit: Click object — drag move; orange handle — rotate; delete on shape/list or Shift+click.
  5. Done: Esc to view mode.

3. Header

  • Search — Geocode or coords.
  • Undo / Redo — 50 steps; lost on refresh or tab close — use Save Plan.
  • Measure ▾ — Distance or area; clear when done.
  • Autosave / Restore Autosave — Browser-only last session.

4. Sidebar

  • Label & Style — Next label, role, color; Snap to selected for add-ons (select target first).
  • Options ▾ — Opacity, rotation, buffer (dashed ring). Mark tight buffer as intentional in list when shown.
  • Custom Size — Place Custom, then map click.
  • Plan — Save Plan / Open Plan; Export ▾ GeoJSON or PDF; Print Fit. Enable 'Print background graphics' in your browser's print dialog for the satellite image to appear.

5. Status bar, overlaps & save

Status bar shows zoom, scale, count, and overlap summary. Red — footprint overlap. Amber — buffer advisory; adjust or mark intentional.

  • Autosave — This browser only; not a backup.
  • Save Plan — JSON file to archive, email, reopen anywhere.
  • Fresh open by default — Restore Autosave for last browser session.

6. Keys

  • / search · Esc view mode · Ctrl+Z / Y undo/redo · P place (when tent selected)
