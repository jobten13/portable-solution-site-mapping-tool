Portable Solution Site Mapping Tool — Quickstart

v1.5.0-dev · August 2026 · One sheet for field operators. Open Portable-Solution-Site-Mapping-Tool.html in Chrome, Edge, or Safari.

1. Open & find your site

Runs directly from the file — nothing to install. Internet connection required.

Fresh start every open: The map opens empty at the default view. Your last layout is not loaded automatically. After a refresh or new tab, click Restore Autosave (same browser) or Open Plan (JSON file). Restore keeps your saved map view; if structures exist but none are on screen, the map fits to them.
  1. Search by address/place — press Enter to search (placeholder reminds you). Results prefer the current map area. When several matches exist, the first is centered and a picker appears — choose the correct one. Dismiss the picker with Esc or an outside click.
  2. Or paste lat, lng coordinates (works offline).
  3. Under Plan, set Plan Name — this names your saved plan and printout.
  4. Layer control (top-right): satellite + Place Labels (Hybrid) for orientation.

2. Header tools

  • Start Here — searchable essential help anytime (not a one-time popup).
  • Snap — true-face align-while-dragging for singleton moves (see Snap section). Hold Ctrl/Cmd while dragging to suppress. Off during multi-structure group moves.
  • Door — place entry marks on any footprint edge; drag along the wall to adjust; Esc exits.
  • Undo / Redo — up to 50 steps (Ctrl+Z / Y; Mac: Cmd+Z). Cleared on refresh — use Save Plan or Restore Autosave.
  • Measure ▾ — distance or area on the map.
  • Print — same as Ctrl/Cmd+P (current view + plan details header + SVG legend).
  • Autosaved … — timestamp for browser backup; Restore Autosave loads it (confirms if layout already has structures).
  • Map-floating readout — shows what you're currently doing (placing, measuring, or which structure(s) are selected); when armed to place, includes ✕ to stop.

3. Place & edit structures

  1. Catalog tab (nine tabs: eight vendors + Power) → click a model (enters place mode). Set role on the card if needed (Manage roles… appears in the role dropdown when custom roles exist). Bed counts on cards show a beds unit.
  2. Click the map to place. Catalog placement stays armed — click again for another of the same model. Disarm: readout ✕, Esc, re-click the armed card, or click a placed object.
  3. Select: click a footprint; Shift, Ctrl, or Cmd+click toggles add/remove; Ctrl/Cmd+A selects all. Selected footprints show a blue double-outline.
  4. Move: drag body — multiple selected structures move together as a rigid group (one undo).
  5. Rotate: drag the ↻ handle (Shift = 5° steps). Groups rotate about their centroid (one undo).
  6. Delete: red map ✕ deletes the current selection (name confirm for one structure; count confirm for two or more). ✕ in the placed list deletes that row only — even if it is part of a multi-selection. Delete / Backspace matches map ✕ behavior.
  7. Custom Size — width / length, optional Beds (single or min–max range), optional label → Place Custom → click map (places once — click Place Custom again for another). Set role Ramp for a ramp footprint (hatch); use where a doorway sits above grade.
  8. Placed header ▾ focuses the list (other sidebar panels hide until ▴).

Placed shows running totals: beds (click to toggle All / Ward·ICU) and sq ft. The ⓘ on the Placed header opens the combined caveat: utilities (water, hygiene, waste) are excluded from footprint totals; bed figures are manufacturer recommendations — actual capacity varies with site-specific use.

4. Snap (align structures)

Turn on Snap in the header (off by default; click again to turn off). Drag a single structure near another and true faces pull flush (including chamfers and irregular footprints); your pre-drag orientation is matched to the nearest 0°/90° relative to the anchor. Hold Ctrl/Cmd while dragging to suppress snap; Esc also turns Snap off. Snap does not run during multi-structure group moves — snap a connector piece first, then rejoin.

5. Spacing & overlaps

Options ▾ (Label & Style) — set clearance buffer (feet), then Apply to Selected for placed structure(s), or presets / Apply Buffer to All for the whole layout.

SignalMeaningAction
RedFootprints physically overlapMove or rotate — must fix
AmberClearance rings conflict (footprints may still be separate)Adjust spacing, or check Intentional in placed list (amber-only rows)

Overlap counts update while you drag or rotate, not only after release. Watch the status bar, sidebar warning under Placed, and the map pill (top-right). Click the pill to cycle through flagged structures (with pulse).

6. Save, export & print

  • Save Plan — portable JSON (archive, email, reopen on any machine).
  • Open Plan — replaces current layout (confirms).
  • Export GeoJSON — GIS handoff.
  • Print or Ctrl/Cmd+P — prints the current view with plan details (name, date, coordinates, beds, sq ft, zones) and an SVG legend for Entry/Exit, Ramp, footprint overlap, and buffer advisory (no auto-fit); if the satellite image is missing from the print, enable Print background graphics in the browser's print settings.
Autosave ≠ backup: Autosave stays in this browser only. Save Plan files for operations handoff.

7. Keyboard shortcuts

  • / — puts your cursor in the search box
  • Esc — leave place/measure/door modes; clear selection; turn Snap off
  • Ctrl/Cmd+A — select all placed structures
  • Delete / Backspace — delete current selection (confirm)
  • Ctrl+Z / Y — undo / redo
  • Hold Ctrl/Cmd while dragging — suppress Snap

Start Here (header) reopens searchable essential help anytime.
