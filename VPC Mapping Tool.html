Scale Presets

  1. Search for a site (address or lat, lng). The app opens with a fresh map — use Restore Autosave if you had work in this browser.
  2. Select a tent from the list (or enter Custom Size and click Place Custom), then click the map to place.
  3. Click a placed object to select it; drag to move, drag the orange handle to rotate. Delete with the red ✕ (confirms), Shift+click the footprint, or ✕ in the placed list.
  4. To attach structures: select the target, check Snap to selected object, pick the tent, click near the face to attach to (unchecks after a successful snap).
  5. Watch overlap counts in the status bar and map pill — red = footprint overlap; amber = clearance conflict (use Intentional on amber-only rows if deliberate).
  6. Use Plan to Save, Open, or Export (GeoJSON/PDF). Undo / Redo in the header (Ctrl+Z / Ctrl+Y).
  7. Press Esc (or click the mode badge) to return to view mode.
