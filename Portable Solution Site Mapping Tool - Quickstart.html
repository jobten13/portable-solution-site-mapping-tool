Portable Solution Site Mapping Tool — Quickstart

v0.8.8 · May 2026 · One sheet for field operators. Open Portable Solution Site Mapping Tool.html in Chrome, Edge, or Safari.

1. Open & find your site

No install. Network helps for map tiles, address search, and PDF export libraries.

Fresh start every open: The map opens empty at the default view. Your last layout is not loaded automatically. After a refresh or new tab, click Restore Autosave (same browser) or Open Plan (JSON file).
Offline: Enter lat, lng in search (e.g. 34.05, -118.25) and press Search. Layout editing works; tiles may not load.
  1. Search by address/place, or paste coordinates.
  2. Setup ▾ — set Operation Name (print/PDF) and scale presets if needed.
  3. Layer control (top-right): satellite + Place Labels (Hybrid) for orientation.

2. Place & edit structures

  1. Vendor tab → click a model (enters place mode).
  2. Click the map to place. Repeat for more structures.
  3. Click a placed object — drag body to move; orange handle to rotate (Shift = 5° steps).
  4. Delete: red ✕ on map, ✕ in placed list, or Shift+click footprint — all ask to confirm.
  5. Custom Size — enter dimensions → Place Custom → click map.

Attach structures (snap)

  1. Select the target structure on the map.
  2. Check Snap to selected object in Label & Style.
  3. Pick the add-on model, click near the face to attach (nearest of four faces wins).
  4. Snap unchecks automatically after a successful attach. Best for rect-to-rect.

3. Spacing & overlaps

Options ▾ — set clearance buffer (feet) for dashed setback rings on the next placement, or use presets / Apply Buffer to All.

SignalMeaningAction
RedFootprints physically overlapMove or rotate — must fix
AmberClearance rings conflict (footprints may still be separate)Adjust spacing, or check Intentional in placed list (amber-only rows)

Watch the status bar, sidebar warning under Placed, and the map pill (top-right). Click the pill to jump to the first flagged structure.

4. Header tools

  • Undo / Redo — up to 50 steps (Ctrl+Z / Y; Mac: Cmd+Z). Cleared on refresh — use Save Plan or Restore Autosave.
  • Measure ▾ — distance or area on the map.
  • Autosaved … — timestamp for browser backup; Restore Autosave loads it (confirms if layout already has structures).

5. Save, export & print

  • Save Plan — portable JSON (archive, email, reopen on any machine).
  • Open Plan — replaces current layout (confirms).
  • Export ▾ — GeoJSON (GIS) or PDF (map snapshot + summary; needs network for libraries).
  • Print Fit — frames all structures; enable Print background graphics for satellite imagery.
Autosave ≠ backup: Autosave stays in this browser only. Save Plan files for operations handoff.

6. Keyboard shortcuts

  • / — focus search
  • P — place selected tent
  • Esc — return to view mode (or click mode badge)
  • Ctrl+Z / Y — undo / redo

Hover controls in the app for more hints (title tooltips on buttons, sliders, and map objects).
